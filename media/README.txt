지금 들어있는 것

첫 화면 영상을 바꾸고 싶으면
- 새 영상을 hero.mp4 라는 같은 이름으로 덮어쓰면 됩니다.
- 첫 장면 사진도 hero.jpg 로 같이 바꿔주세요.
- 소리는 반드시 없어야 합니다. 있으면 브라우저가 자동재생을 막습니다.
- 10~20초, 5MB 안쪽이 좋습니다. 무거우면 폰에서 안 뜹니다.

새 파일을 넣을 때
- 파일 이름은 영어와 숫자로 쓰세요. 한글 이름은 서버에 따라 깨질 수 있습니다.
- 사진은 jpg, 영상은 mp4 로 넣으세요.
- <img> 나 <video> 에 height="..." 를 적지 마세요. 비율이 깨집니다.
  style 에 height:auto 를 같이 주세요.
